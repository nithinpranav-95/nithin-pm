# Minimalist Monograph

Design a website that  is in structural minimalist editorial style.
this should be used as portfolio for a product manager

Key traits:

Dark, near-monochrome base — deep black background with light text and thin border lines.

Modular panel layout — the page reads like a spread or a monograph, with content boxed into bordered sections.

Typography-led hierarchy — large display name, clean sans-serif body (Inter), and mono metadata (JetBrains Mono) for labels, dates, and nav.

Restrained accent — a single warm orange used sparingly for emphasis and interactive states.

Generous whitespace — lots of breathing room, no heavy shadows or gradients.
